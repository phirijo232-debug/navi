# BMF

This is the BMF loan application.

- Live branch: `Published-BMF-Branch`
- Test branch: `bmf-staging`

Before changing the live app, follow [TESTING_RULES.md](TESTING_RULES.md). Every change starts on a feature branch off `bmf-staging`, is tested there, and is only then merged into `Published-BMF-Branch`.

A test website and test database will be set up later.
